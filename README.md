# landsat-descision-tree-clasifier

Using a LandSat image of the area over Madsion WI, I used QGIS to create a virtual raster of a false color image using bands 3,4 and 5. I then created a point shp layer for my training data. I used about 50 points; understanding this is very small for an accurate machine learning algorythm. I had about half labeled as vegetated and half as non vegetated. When I ran it through the code I had 41 training points and 11 testingo of which 6 were vegetated and 5 were non vegetated. I got a final accuracy of 91% using the Gini Index. The scikit-learn algorythm ended up using band 5 as the root node which makes sense as band 5 is the Near Infrared and is what is most heaivily reflected by vegetation. That being the case, I found it interesting that the algorythm chose band 1 as the second level threshold because typically band 5 is what is used to determine vegetation levels. However, some of the training data came from the lakes that surround the Madison area and according to USGS about the coastal aerosol band 1, "Scientists have used the coastal band to monitor chlorophyll concentrations and suspended sediments in the water, as well as phytoplankton and algae blooms." I would like to continue working on this project and increase the accuracy by 1. Increasing the sample size of the training data, and 2. Instead of a singledescision tree, I want to implement a random forest classification scheme instead of a single descision tree.
